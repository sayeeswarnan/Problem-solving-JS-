Welcome to my **JavaScript Problem-Solving Repository**! 🚀  
This repository documents my structured journey of mastering **Data Structures, Algorithms (DSA)**, and standard interview preparation patterns like **Blind 75** using modern **JavaScript (ES6+)**.

---

## 📌 Repository Overview

The codebase is organized into two primary tracks:

1. 🎯 **`PS/` (Core Problem Solving & Fundamental DSA Patterns)**: Comprehensive practice covering fundamental algorithmic concepts starting from basic math and recursion up to advanced sorting and hashing techniques.
2. 🏆 **`Blind_75/` (Blind 75 LeetCode Track)**: Solutions to the top 75 curated LeetCode problems categorized by pattern and difficulty for coding interview preparation.

## 🛠️ How to Run the Code

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

To run any script, navigate to the project root directory in your terminal and execute:

```bash
# Example: Run Merge Sort
node PS/Sorting/Merge_sort.js

# Example: Run Product Except Self (Blind 75)
node Blind_75/Array/Product_Except_self.js

# Example: Run Recursion practice
node PS/Recursion/10.fibonaci_recursion.js
```
